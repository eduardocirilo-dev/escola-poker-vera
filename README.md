# Escola de Póquer · Vera

**A app abre aqui → <https://eduardocirilo-dev.github.io/escola-poker-vera/>**

O `index.html` deste repositório é o código da app (a «oficina» onde ela está guardada).
Para **usar** a app, abre o endereço acima — abre no telemóvel e no computador, sem instalar nada.

## O que é

Treino de póquer para quem nunca jogou: 13 lições curtas, 16 sessões de 20 perguntas e um desafio
cronometrado com medalhas. Ranges dos 5 spots binários do sistema Quintas (2,5 a 9,5 BB),
geradas e conferidas a partir de `posicoes.json` (0 divergências contra `quintas-pushfold.json`).

O progresso fica guardado no próprio aparelho (não sincroniza entre telemóvel e computador).
